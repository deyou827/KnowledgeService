# 验证范围

后续按成本和依赖分层建立，分别运行：

| 目录 | 内容 | 条件 |
| --- | --- | --- |
| `unit` | 领域、契约、幂等、版本、状态 | 合成数据，不调模型，不联网 |
| `security` | 身份角色矩阵、跨租户／空间隔离、SSRF、解析隔离、提示注入 | 合成数据 |
| `integration` | 真实 PostgreSQL 迁移与事务、对象存储、OIDC | 需单独说明条件，不能用 Mock 通过替代 |
| `fault` | 租约过期、重复任务、并发发布、发布中删除、Outbox 重放 | 真实数据库 |
| `evaluation` | 固定数据集、检索与问答质量 | 调用前确认外发范围与预算 |
| `fixtures` | 合成资料、至少两个租户的夹具 | 不含个人文档 |

重点覆盖：跨作用域隔离、撤权、幂等冲突、摄取失败不发布、文档删除、索引切换、引用绑定及历史回读。S1a 增加依赖方向检查，把 `domain` 不导入框架等规则变成自动测试。

目录在对应阶段按需建立。测试使用合成资料和临时存储，不扫描个人目录。
